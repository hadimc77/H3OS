# H3OS Roadmap

## 0.1 Horizon — foundation (current)
Bootable hybrid kernel, memory, interrupts, Horizon desktop, terminal, VFS.

## 0.2 Aurora — userspace
Ring-3 processes, ELF loader, real context switch, libc subset, pipes.

## 0.3 Bedrock — storage
AHCI/NVMe, H3FS journaling, EXT2 read, FAT32 R/W, installer image.

## 0.4 Nexus — networking
Virtio-net / e1000, TCP/IP, DNS, DHCP, HTTPS (userspace), SSH daemon.

## 0.5 Prism — media & GPU
Virtio-GPU / VESA accel path, audio, richer WM effects, multi-monitor.

## 0.6 Forge — developers
SDK freeze, debugger, profiler, h3pkg repositories, sample apps.

## 1.0 Genesis — release
Secure Boot signing, firewall, sandboxing, documentation complete, ISO installer.
